# agentic-pdf agent guide

Fill PDF fields, merge files, and split one PDF. All faces return the same JSON shapes.

- SDK: `import { fillPdf } from "agentic-pdf"`.
- CLI: `agentic-pdf fill ...`.
- MCP: `fill_pdf`, `merge_pdfs`, and `split_pdf`.

Dry run is the default. Use `--live` only after a preview looks right.
